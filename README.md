# qq-agent-mood

给 QQ Agent 里的 AI 角色一颗**会变的心**。

被骂会掉分，被夸会涨分，被真心哄能回来；分数落在哪一档，说话的语气、长短、愿不愿意开口，就跟着变。
同一个方向连着来，一次比一次轻——她不会因为同一句话被记两遍仇。

纯插件：不改应用源码，装上是加一个文件夹，卸掉是删一个文件夹。想让心情真的压住「回几条、回不回」，另有**可选补丁**（见下）。

## 装

不想看源码就从 [Releases](https://github.com/Jinchuan114/qq-agent-mood/releases) 下 `qq-agent-mood.zip`，解出来就是一个 `qq-agent-mood` 文件夹，直接跳到第 1 步。

1. 把 `qq-agent-mood` 整个文件夹放进：

   ```
   <QQ Agent 安装目录>\resources\app\plugins\qq-agent-mood
   ```

2. 应用会自动发现并热加载（日志里会出现「加载成功：心情（她有情绪）」）。
   没动静就在「技能」页刷新一下，或者发一次 `POST /api/skills/reload`。
3. 打开「设置 → 技能 → 心情（她有情绪）」，确认「开启心情」是开着的。

装好就开始记，不用配任何东西。

> **如果你之前装过带情绪的其它插件**：把那个技能的 `mood` 选项设成 false 能关掉它往提示词里贴的那一段，但**它可能还在后台判分、写自己的文件**（各版本实现不同，关不干净的话会两套一起记）。新装用户没有这个问题。

**面板**：默认 `http://127.0.0.1:3221`，端口可在设置里改。只监听本机，别人连不上。

## 它怎么记

| 别人说了什么 | 记成 | 默认变化 |
|---|---|---|
| 骂她、贬低她、让她滚 | 被骂 insult | −40 |
| 「行了行了」「多大点事」 | 敷衍 dull | −10 |
| 被骂但觉得好笑 | 当成玩笑 tease | −12 |
| 夸她、说喜欢她 | 被夸 praise | +12 |
| 主人真心哄、站她这边 | 被哄（主人） | +35 |
| 别人真心哄 | 被哄（别人） | +8 |

**脾气倍率（temper）**乘在上面这六条上，不乘分数：0.7 更皮实，1.4 更敏感，范围 0.5～2.0。

分数范围 −100～+100，0 是平常：

- **≤ −60** 懒得理
- **≤ −20** 不高兴
- **≥ +20** 高兴
- **≥ +60** 特别高兴

每小时往 0 回一点，默认 6 小时缓过来。回落是**读的时候按时间算**的，不靠后台任务，所以关掉应用那几个小时也算。

**连续递减**：同一个方向连着来，系数是 `1 / (1 + k·0.6·n)`（n = 之前已经连续推了几次）。
强度 `中`（k=1）：−40 → −25 → −18。反方向不打折，从头算。设置里可以调成 关 / 轻 / 中 / 强。

## 她怎么「表现」出来

- 每轮发模型之前，按档位往最后一条用户消息末尾贴一小段：**只有跨档才贴**（平常、以及 0～+19 这种没跨档的不贴，省 token）。设置里「平常也贴心情行」可以强制每轮都贴。
- 贴的内容只讲语气和行为，明写「别报分数、别说我心情值多少」。
- 她自己也有一个工具「记一下心情」（`note_mood`），觉得自己被戳到、被哄好时调一次；她自己记的覆盖程序的预判。

---

## 谁会「判」

开着「让模型判断」时，每来一句话多一次很短的小模型调用（只输出一个分类词）。用的是应用自己的接口和 Key；也能单独填「判官用哪个模型 / 接口地址 / Key」，想省钱就指一个便宜的小模型。

关掉它就走关键词规则：一分钱不花，但会漏（「你这人挺废的」认不出）也会误（「这游戏真难受」可能被当成在哄）。
每日有次数上限（默认 300），超了、超时、报错，一律退回关键词，**绝不卡住她的回复**。

## 可选补丁：让心情影响「回不回」

默认**不影响**：心情只改语气，不会让她突然不理人。

想要更硬的效果（不高兴时少发几条、懒得理时真的不说话），跑一次：

```bash
node plugins/qq-agent-mood/patch/install.mjs
```

- 改的是应用的 `src/orchestrator.js` 和 `src/tools.js`，把写死的情绪调用换成插件提供的「能力门」
  （`mood.bubble-cap` 控条数、`mood.mute-rate` 控静音概率）。
- 改之前按锚点+哈希校验，对得上才动；备份成 `*.bak-before-qq-agent-mood`；原子写。
- 对不上（版本变了）就一个字节都不动，只告诉你原因。
- 应用升级后可能要重新装一次。

还原：

```bash
node plugins/qq-agent-mood/patch/install.mjs --undo
```

它直接拿备份盖回去（不是反推替换），会把打补丁后的版本留一份 `*.patched-<时间戳>`。打完补丁要重启应用。

## 卸载

1. 关掉 QQ Agent
2. 删掉 `plugins/qq-agent-mood` 整个文件夹
3. 想连心情数据一起清干净，删掉：

   ```
   <数据目录>\self\qq-agent-mood\
   ```

   不删的话，下次装回来会接着原来的分数。
   （数据目录默认是 `<QQ Agent 安装目录>\data`，被 `QQ_AGENT_DATA_DIR` 覆盖时按那个算。）

打过补丁的，**先 `--undo` 再删文件夹**，否则还原脚本跟着一起没了。

## 面板能干什么

- 看现在多少分、哪一档、最近几笔记了什么（谁说的、为什么、加/减多少）
- 拖心情条直接改分（当调试用：想看「不高兴」长什么样，拖过去就行）
- 四个常用旋钮：脾气倍率、多久消气、心情低时的表现、判官开不开
- 高级折叠里有六类权重、四档阈值、递减强度
- 「试一句」：真记一笔，立刻能在分数条上看到

面板不自己存配置，所有设置都写回应用（`config.skills['qq-agent-mood']`），所以改完 App 里也一致。
如果应用没起来，面板改设置会**明确报错**，不会假装成功。

## 排查

| 现象 | 看哪里 |
|---|---|
| 装了但分数一直不动 | 「让模型判断」开着的话，看判官有没有额度/接口通不通；也可以发一句「你好可爱」这种关键词能命中的试试 |
| 不知道该不该贴心情行 | 看 `<数据目录>\self\qq-agent-mood\hook.log`，每次钩子进出、算出多少分、贴没贴都记一行 |
| 面板打不开 | 端口被占会往后顺延，插件日志里会写实际端口；也可在设置里改 `面板端口` |
| 改了设置不生效 | 设置是热读的，下一句生效；技能本身没热加载的话发 `POST /api/skills/reload` |

插件自己的 `console.log` 不会进应用日志（Electron 主进程没收 stdout），所以排查一律写文件，别指望日志面板。

## 自测

```bash
node test/run.mjs      # 纯函数 + 记分 + 贴心情行（38 项，不碰数据）
node test/e2e.mjs      # 真插件跑在临时目录里，含面板（18 项）
QQ_AGENT_SRC=<安装目录>/resources/app/src node test/patch.mjs   # 补丁：打→幂等→还原（15 项）
```

三个都不需要联网。`test/patch.mjs` 必须在**临时目录里复制真应用源码**来打，不会动你的安装。

## 隐私

- 不联网、不上传、不统计。判官只用你自己的模型接口
- 只把分数、档位、一句「为什么」存在本地，昵称只存昵称，不存 QQ 号
- 面板只监听 `127.0.0.1`
- 订阅接口地址、Key 都只在应用配置里，插件不另存一份
